Qué espera la app

Un archivo Excel con las tablas usadas por el dashboard. Podés reemplazarlo cuando tengas una versión nueva.

Qué pasa al reemplazar

El estado actual se sobrescribe con el archivo nuevo y la app vuelve a calcular el snapshot local.

Qué no se sube

El archivo se procesa localmente en este navegador. No se envía a ningún servidor.
